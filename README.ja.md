# SD Meta Editor

> **ステータス: pre-alpha — 設計段階。アプリケーションコードは未着手です。**

生成 AI 画像（Stable Diffusion 系）に埋め込まれたメタデータを**確認・編集し、確実に削除する**ための、高速なクロスプラットフォームデスクトップアプリ。

---

## 何のためのツールか

この種のツールを使いたい人の多くは、メタデータを*編集*したいのではなく、**公開前に確実に消えていることを確かめたい**。プロンプト、LoRA 名、マージレシピ、サンプラー設定は、本人が思っている以上に「どう作ったか」を暴露します。

SD Meta Editor はその目的のために作られています。中核的な価値は「フィールドを編集できること」ではなく、**「本当に消えたと確信できること」**です。

## 設計目標

| 目標 | 実現方法 |
|---|---|
| **消し残さない** | 見落としやすい経路を網羅：`zTXt`、`eXIf`、XMP、MakerNote、GPS、EXIF 埋め込みサムネイル、C2PA JUMBF、アルファ LSB ステガノグラフィ（stealth PNG） |
| **劣化させない** | メタデータは画素データの外側にある。保存時はコンテナのチャンクだけを書き換え、画像ビットストリームはバイト列のままコピーする。デコードも再エンコードもしない |
| **速い** | ロスレス保存はほぼファイルコピーのコスト |
| **固まらない** | すべての I/O とデコードを UI スレッドの外で実行。キー入力ごとの IPC 往復を行わない |
| **自己検証する** | 保存のたびにファイルを読み直し、何も残っていないことを確認する |

## v1 の予定機能

- JPEG / PNG / WebP — ドラッグ&ドロップ、ファイルダイアログ、OS 関連付け、クリップボード
- A1111 / Forge / Forge Neo 形式の構造化パース
- ComfyUI・未知形式向けの Raw チャンク表示＋保持/削除トグル
- 削除プリセット（プロンプト、LoRA、Seed、モデル・環境情報、拡張機能、全削除）
- フォルダ単位の一括処理
- stealth PNG の検出・除去
- 元形式を維持した書き出し（`_edited` サフィックス付き）
- 任意の再エンコードモード（品質設定可）

## 既知の制限

**SynthID 等の画素内不可視透かしは本ツールでは除去できません。** メタデータを消しても画像が追跡不能になるわけではありません。曖昧にせず明記します。

## アーキテクチャ

```
crates/sdmeta-core/   pure Rust。パース・編集・ロスレス書き出し。GUI 非依存・単体テスト対象
crates/sdmeta-cli/    一括処理と形式調査のための CLI
app/                  Tauri 2 シェル（Rust バックエンド + React/TypeScript フロントエンド）
```

最も難しい部分（バイト列レベルのコンテナ操作）を GUI 非依存のクレートに置くことで、GUI なしでテストでき、CLI が副産物として得られます。

## 動作環境

| プラットフォーム | 状態 |
|---|---|
| macOS（**Apple Silicon** / arm64） | 主対象 |
| Linux（x86_64） | 予定 |
| Windows | 保留 |

**Intel Mac は対象外です。** macOS 版のビルドターゲットは `aarch64-apple-darwin` 単体で、
Intel Mac では起動しません。判断の理由は [ADR-0008](docs/adr/0008-apple-silicon-only.md) に記載しています。
