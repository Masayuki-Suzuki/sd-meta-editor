# ADR-0013: 最低対応 macOS バージョンを 14.6 とする

- Status: Accepted
- 日付: 2026-11-17
- 関連: [ADR-0008](0008-apple-silicon-only.md)（Apple Silicon 限定）、[ADR-0009](0009-local-builds-all-three-os.md)（実機ビルド）

## Context

ADR-0008 で macOS 版を Apple Silicon 限定としたが、OS バージョンの下限は明示していなかった。

技術的な下限と、検証可能な下限は一致しない。

- **Tauri 2 の下限は macOS 10.15** である。フレームワーク上の制約はここまで緩い
- **Apple Silicon の下限は macOS 11 Big Sur** である。初代 M1 Mac がこれを搭載して出荷された
- **検証できる下限は開発機の macOS 14.6（Sonoma、Apple M1 Max）** である。
  それより古いバージョンの実機がない

ADR-0009 で定めたとおり、本プロジェクトは「実機で検証できない環境向けには配布しない」
方針を取っている（ADR-0008 で Intel 専用ビルドを却下したのと同じ理由）。
この方針に従うなら、下限は検証可能な 14.6 になる。

## Decision

**最低対応バージョンを macOS 14.6 とする。**

Tauri のバンドル設定（`minimumSystemVersion`）にも 14.6 を指定し、
それより古い環境では**インストール時に明確に弾く**。

これは**技術的な下限ではなく、検証済みの下限**である。macOS 11〜13 の
Apple Silicon Mac でもおそらく動作するが、確認していないものを
「対応」と称さない。

## 却下した案

**Tauri の下限に合わせて 10.15 とする** — Apple Silicon 限定（ADR-0008）と
矛盾する。Intel 専用の macOS バージョンを下限に書く意味がない。

**Apple Silicon の下限に合わせて 11.0 とする** — 利用可能な範囲は最大になるが、
macOS 11〜13 を一切検証できない。「動くはず」で配布した結果として
起動しない・保存が壊れるといった不具合を見逃すリスクを取ることになる。
本アプリは画像ファイルを書き出すツールなので、このリスクは取らない。

**下限を 11.0 と宣言しつつ「14.6 以降のみ検証済み」と注記する** — 一見誠実だが、
利用者から見れば「対応と書いてあるのに動かない」が起こりうる状態である。
インストールできてしまう方が、弾かれるより体験が悪い。

## Consequences

- macOS 11〜13 を使っている Apple Silicon ユーザーは利用できない。
  README の動作環境に明記する
- 開発機を更新した場合、**下限が自動的に上がるわけではない**。
  下限は意識的に決める値であり、OS を上げたら ADR を起こして見直す
- 下限を下げるコストは小さい。該当バージョンの実機（または検証環境）が
  用意できた時点で、バンドル設定を変えて検証すればよい

## 再検討の条件

- macOS 11〜13 の実機、または検証に使える環境が用意できた場合
- 利用者から当該バージョンでの要望が寄せられた場合。ただし
  ADR-0009 のとおり、**実機で検証できない限り「未検証」の扱いを明記する**
- 開発機の macOS を更新した場合（下限を上げるかどうかを改めて判断する）
