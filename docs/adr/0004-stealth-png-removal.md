# ADR-0004: stealth PNG の検出・除去を v1 必須機能とする

**Status:** Accepted
**Date:** 2026-11-12

## Context

NovelAI 系が使う stealth PNG は、メタデータを**アルファチャンネル各画素の最下位ビット（LSB）**に埋め込む。tEXt / iTXt チャンクや EXIF をすべて削除しても**一切消えない**。

本ツールの主用途が削除である以上、「消えたと表示したが実際には残っている」状態はバグではなく**安全上の欠陥**にあたる。

## Decision

検出と除去の両方を v1 に含める。検出のみの中間案は採らない。

## Rationale（却下案の記録）

| 案 | 却下理由 |
|---|---|
| 検出して警告するのみ（除去は v2） | ユーザーが自力で解決できない。「検出したが消せません」は実用上不完全 |
| v2 送り | チャンク削除だけで「完了」と表示することになり、**偽の安心を与える点で機能がないより有害** |

## 技術仕様

### データ構造（`stealth_pnginfo` 実装準拠）

```
[シグネチャ文字列][32bit データ長][ペイロード(UTF-8 JSON)]
```

- シグネチャ: `stealth_pnginfo`（非圧縮）/ `stealth_pngcomp`（gzip）/ `stealth_rgbinfo` / `stealth_rgbcomp`（アルファ無し画像向け RGB 版）
- ビット読み出し順: 左上から**列優先（column-major）**
- 対象: PNG および WebP lossless。**JPEG と WebP lossy は非該当**（非可逆圧縮で LSB が保存されないため）

### 検出

シグネチャは先頭にあるため、**冒頭の数百ビットを読むだけで判定可能**。全画素走査は不要であり、性能目標に影響しない。

### 除去

アルファチャンネル全画素の LSB を **0 にクリア**する。ランダム化ではなく決定的クリアとし、検証可能性を優先する。

- 視覚的影響: α=255 の画素が α=254 になる程度で知覚不能
- 代替案「アルファチャンネルを削除して RGB 化」は、完全不透明画像なら無損失だが**透過画像で使えない**ため不採用
- 検出されなかった場合は LSB に触れない

## Consequences

**ロスレス書き出し原則の唯一の例外となる。**

LSB 操作は画素の書き換えであり、IDAT の再生成（PNG 再エンコード）が必要になる。

- 適用範囲は **PNG / WebP lossless かつ stealth が検出された場合のみ**に限定する
- 該当時は保存時間が伸びる（10MB で数百 ms 程度）。UI に「ステガノグラフィ除去のため再エンコード中」と明示する
- PNG の再エンコードはロスレスなので画質劣化は発生しない
- 除去後は保存後検証（要件定義書 FR-7）で再検出を走らせ、0 件を確認してから完了表示する

## UI 要件

stealth 検出時は、通常のメタデータ一覧とは別に警告バナーを出す。文面は「通常のメタデータ削除では除去できない隠しデータを検出しました」とし、**チャンク削除だけでは不十分であることをユーザーに理解させる**。

## 関連する制限

SynthID 等の**画素内不可視透かし（Google Imagen / Gemini 系）は本ツールでは除去できない**。これは README とアプリ内に明記する。「全部消えた」と誤認させることは本 ADR の思想に反する。

## 再検討のトリガー

- stealth 埋め込みの実装仕様が変更された場合
- 他の画素内埋め込み方式が広く使われるようになった場合
