# ADR-0009: 3 OS すべてを実機ローカルビルドで対象とし、対応 OS バージョンを確定する

- Status: Accepted
- 日付: 2026-11-17
- 関連: [ADR-0007](0007-ci-abolished-local-builds.md) のビルド環境表と派生制約 C-12 を置き換える

## Context

ADR-0007 では Linux を「Mac 上の Linux コンテナ」、Windows を「保留」とした。
この判断は 2 つの前提に立っていた。

1. GitHub Actions の分数コスト（`macos-latest` 10 倍、`windows-latest` 2 倍）
2. 開発者の実機が Mac のみであるという想定

前提 2 が誤りだった。**開発者は macOS・Windows・Ubuntu の 3 OS の実機を保有している。**
これによりコスト要因である Actions を使わずに、3 OS すべてで実機ビルドと実機テストが
可能になる。Windows を保留にしていた理由は Actions の分数コストだったため、
ローカルビルドに切り替わった時点でこの理由は消滅する。

Mac 上の Linux コンテナという案も不要になった。Apple Silicon のネイティブコンテナは
arm64 であり、Linux デスクトップの主流である x86_64 向けの成果物を得るには
エミュレーションが必要で、Rust のビルドが大幅に遅くなる。実機の Ubuntu があるなら
そちらの方が速く、かつ実際の配布対象と同一の環境で検証できる。

## Decision

**3 OS すべてを対象とし、すべて実機でローカルビルドする。**

| ターゲット | ビルド・テスト環境 | 対応バージョン |
|---|---|---|
| macOS（Apple Silicon / arm64） | 開発機の Mac | [ADR-0008](0008-apple-silicon-only.md) により arm64 のみ |
| Windows | Windows 実機 | **Windows 11 のみ** |
| Linux（x86_64） | Ubuntu 実機 | **Ubuntu 24.04 LTS 系（24.x）** |

### 旧バージョンの扱い

上記より古い OS バージョンには対応しない。ただし以下の条件が揃った場合に検討する。

- 当該 OS の実機を保有し、
- 自身でビルドと**テストまで実行できる**コントリビューターが現れた場合

現時点で必要性は低いと判断している。この方針は ADR-0008 の
「検証できない環境向けの配布はしない」という考え方と一貫している。
実機で検証できない環境のバイナリを配布すると、起動しない・保存が壊れるといった
不具合を発見できないまま公開することになる。本アプリは画像ファイルを書き出す
ツールであり、そのリスクは取らない。

### C-13. ロスレス書き出しの検証範囲

ADR-0007 の C-12（Windows 実機での検証）を、3 OS すべてに拡張する。

> ロスレス書き出しパスは、**macOS・Windows 11・Ubuntu 24.04 の 3 実機すべてで**
> ファイルの上書き・リネーム・同時オープンの挙動を検証するまで
> 「動作確認済み」と見なさない。

C-12 が Windows のみを対象としていたのは、当時 Linux がコンテナ前提で実機検証が
想定されていなかったためである。3 OS の実機が使える前提では、Linux も同じ基準で
検証すべきである。

## 却下した案

**Mac 上の Linux コンテナを使う（ADR-0007 の当初案）** — arm64 コンテナでは
x86_64 向けの成果物が得られず、`--platform linux/amd64` でのエミュレーションは
Rust のビルドが遅い。実機 Ubuntu があるなら利点がない。

**GitHub Actions に戻す** — ADR-0007 の判断を覆す理由がない。課金ロックが
未解消であり、private リポジトリでの分数倍率も変わっていない。

**Windows 10 にも対応する** — Microsoft の Windows 10 サポートは 2025 年 10 月 14 日に
終了している。サポート終了済み OS 向けに検証コストを払う理由がない。

**Ubuntu 以外のディストリビューションも対象に含める** — Tauri の Linux 版は
WebKitGTK 4.1 に依存し、ディストリ差で描画バグが出ることが ADR-0001 で既知のリスクと
されている。検証できるのは手元の Ubuntu 24.04 だけなので、対象を明示して
それ以外は「動作するかもしれないが未検証」とする。

## Consequences

- ADR-0007 のビルド環境表は本 ADR の表で置き換わる。Linux のコンテナ案は取り下げ、
  Windows の保留も解除される
- ADR-0007 の派生制約 C-12 は本 ADR の C-13 に置き換わる
- 要件定義書 §7 の未決事項から「Linux ビルドのコンテナのベースイメージとアーキテクチャ」が
  不要になる。一方、**Windows が対象に戻ったためコード署名の Windows 証明書が
  再び論点になる**
- Ubuntu 24.04 は WebKitGTK 4.1 を提供するため、ADR-0001 が想定した
  `libwebkit2gtk-4.1-dev` の前提と一致する
- 3 OS で手動検証する手順が必要になる。実装開始時に検証チェックリストを用意する
- `release.yml` は引き続き未使用。3 OS すべてがローカルビルドになったため、
  このワークフローの存在意義はさらに薄い。削除は別途判断する

## ADR-0007 の Status を変更しない理由

ADR-0008 と同じ理由による。ADR-0007 の決定事項は「CI を廃止する」であり、
この判断は変わっていない。変更したのはビルド環境の割り当てと派生制約という
一部分である。ADR-0007 全体を `Superseded` にすると「CI を再導入した」と
読めてしまうため、本 ADR で置き換え範囲を明示する方法を取る。
